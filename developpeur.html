Mes projets de développement

Les applications que j’ai développées en tant que développeur web et mobile junior.

01 / APPLICATION WEB · APPRENTISSAGE

Site d’apprentissage des langages de programmation

Plateforme web pédagogique permettant d’apprendre les langages de programmation à son rythme, avec cours, exemples de code et exercices.

  • Catalogue de langages (HTML, CSS, JavaScript, Python, PHP, Java, C) organisé par fiches de cours.
  • Exemples de code commentés et exercices pratiques corrigés pour chaque leçon.
  • Système d’inscription et de connexion avec suivi de la progression de chaque apprenant.
  • Base de données MySQL pour gérer les comptes, les cours et les résultats.
  • Interface responsive utilisable sur ordinateur, tablette et mobile.
VueJavaScriptPHPMySQL
02 / APPLICATION WEB · RÉSEAUX

Application de monitoring réseau

Tableau de bord de supervision permettant de surveiller l’état des équipements réseau en temps réel.

  • Collecte des métriques des équipements : disponibilité, latence, trafic et charge.
  • Graphiques et tableaux de bord pour visualiser l’évolution de l’état du réseau.
  • Alertes automatiques envoyées dès qu’une panne ou une dégradation est détectée.
  • API REST pour centraliser les données remontées par les équipements.
  • Interface d’administration pour ajouter ou retirer les équipements à surveiller.
PythonDjangoJavaScriptAPI REST
03 / E-COMMERCE · BOUTIQUE

Boutique en ligne

Site e-commerce complet : vitrine de produits, panier, commandes et espace client, du front au back-end.

  • Catalogue de produits avec catégories, recherche, filtres et fiches détaillées.
  • Panier, tunnel de commande et gestion des commandes côté client.
  • Espace administrateur pour gérer les produits, les stocks et les commandes.
  • Interface responsive pensée pour la vente sur mobile.
  • Backend et base de données pour gérer utilisateurs, produits et commandes.
ReactJavaScriptCSSAPI REST
